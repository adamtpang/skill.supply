## Draft behavior

The tool:

- resolves or reopens a repository Secret Scanning alert;
- requires `owner`, `repo`, `alertNumber`, and `state`;
- requires a valid resolution when state is `resolved`;
- rejects resolution data when state is `open`;
- explicitly says that changing alert state does not revoke the exposed secret;
- requires the `security_events` scope;
- declares the write as idempotent, non-destructive, and open-world;
- uses the official `go-github` update method;
- labels the returned security-alert payload private-untrusted because the API
  response can contain matched secret material; and
- registers the tool in the Secret Protection toolset.
